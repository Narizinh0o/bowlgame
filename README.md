# КЛБ Боулинг-Батл

Фановая браузерная игра-автобатлер: драфтишь команду из реальных игроков КЛБ и смотришь
матч в боулинг по системе Бейкера. Отдельный проект, к сайту bowlrus не привязан.

Вся спецификация и план работ: **GAME_PLAN.md**.

```powershell
npm install          # один раз
npm run dev          # дев-сервер
npm run sim          # балансовый прогон движка + автопроверки
npm run roster       # обновить снапшот игроков из соседнего репо ../bowlrus
npm run build        # typecheck + прод-сборка
```
